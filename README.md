# From prompt to a live prototype with Claude and GitHub Pages

A step-by-step guide for UX students with no coding experience. It covers using the **free Claude plan** to turn a prompt from the Vibe Coding Prompt Studio into a clickable, single-file HTML prototype, then publishing it on **GitHub Pages** so it can be shared with participants for user testing.

## What's in the guide

- **Workspace tour:** four short videos on the screens of the free Claude plan (home, Projects, Artifacts, Customize).
- **Part 1: Build it in Claude:** nine steps, from copying the prompt to exporting and checking `index.html`.
- **Part 2: Publish it on GitHub Pages:** seven steps, from creating a repository to a live link, README and description.
- Short videos for every step, copy-ready prompts, checklists and troubleshooting.

## Files

| File / folder | Description |

| `github-videos/` | Seven videos, one for each step in Part 2. |

## How to use it

Open the GitHub Pages link for this repository, or open `index.html` in a browser. It needs an internet connection for its web fonts. Progress ticks are saved in your browser.
